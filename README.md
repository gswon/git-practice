# Git Practice
[The future of practice: Enabling teachers to create learning interactives with generative UI](https://research.google/blog/the-future-of-practice-enabling-teachers-to-create-learning-interactives-with-generative-ui/) - *Google Research, September 2026*

I picked this article because I didn't know AI could make an interactive web pages from scratch. Basically, a teacher types in a topic, and the AI builds a small simulation game for students with different levels, hints, and feedback. Google calls this "generative UI." We just went over HTML, CSS, and JavaScript in class, so it was kind of crazy to think that an AI is writing all of that on its own, and making a different version for each teacher's class.

The part that surprised me the most was how they check if the pages actually work. They have an AI open Chrome and click around like a student, and it even tries to break things on purpose, like cranking the sliders all the way up. If something fails, it fixes it and tries again. After that a real teacher still has to approve it before anyone can use it, which honestly sounds a lot like reviewing a pull request. It made me think that even if AI ends up writing a lot of the code, people will still need to know how to test it and review it.
